# Airbnb Pricing Analysis Dashboard

Interactive visualization of pricing patterns across European cities using Streamlit.

## 📊 Features

- **52,810 Airbnb listings** across 10 major European cities
- **Interactive filters** for cities and price ranges
- **Tourism demand analysis** with correlation insights
- **Location impact** visualization (city center, metro, airport)
- **Price comparison** across cities and room types
- **Feature correlation heatmap**

## 🚀 Quick Start

### Local Installation

```bash
# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run streamlit_dashboard.py
```

The dashboard will open in your browser at `http://localhost:8501`

## 📁 Files

- `streamlit_dashboard.py` - Main Streamlit application
- `dataset.csv` - Airbnb listings dataset
- `requirements.txt` - Python dependencies
